## Sentinel GRC training project

`grc/sentinel/index.html` provides the public project context; `grc/sentinel/workspace.html` contains the interactive registers, dashboard, scoring method and guide. The linked Excel workbook is the latest user-supplied fictional training artifact, preserved unchanged, not an employer record. R-001 (Missing MFA), R-002 (Excessive Access Permissions), R-003 (Shared Administrator Accounts) and R-004 (Missing Formal Cybersecurity Risk Register) each use likelihood 3, impact 4 and score 12 High, pending validation. Each risk now has a supplied proposed control, planned evidence request and proposed remediation action. Dashboard readiness, executive insights, scorecards and priority actions distinguish implementation from verified closure. Risk-register evidence references E-001 through E-004 are populated; evidence remains at planned-request status. Portfolio deliverables are complete, not evidence collection, control testing or remediation. Closure requires approval, a valid nonfuture completion date, validated closure and one unique same-risk evidence record that is reviewed and validated, with a valid nonfuture received date, location and reviewer. No production deployment or validated finding is claimed.

Scoring bands follow the latest supplied workbook: Low 1–5, Moderate 6–11, High 12–19 and Critical 20–25. The change record documents the superseded Low/Moderate boundary. Website edits are browser-local; they neither modify the downloadable workbook nor synchronize across visitors. Public visitors should not enter confidential or production evidence.
