PLANNED INDEPENDENT LAB

Access Control Test and Retest Plan

This is the next practical exercise for the Sentinel learning workflow. Execution has not been performed or recorded.

Objective

Evaluate a least-privilege control using test accounts and a protected folder in an isolated Windows lab.

  1. Define the lab host, test accounts, protected folder, expected permissions and assessment date.
  2. Record the initial permissions and group membership using screenshots or exports containing only test data.
  3. Attempt access with an authorized account and an unauthorized test account. Record the actual outcome of each attempt.
  4. Compare expected and observed access. Document any finding and its evidence.
  5. If a gap exists, change only the lab permissions, then repeat the same tests.
  6. Link before-and-after evidence to the finding, retest result and closure rationale. If there is no gap, record that outcome without inventing remediation.

Evidence Record

For each test: identifier, timestamp, host, account, expected outcome, actual outcome, evidence reference and assessor explanation. A single retest demonstrates that test result; operating effectiveness over time needs repeated evidence for a defined period.

Connection to Sentinel

Use the exercise to practice evidence collection for excessive-access risk R-002. Lab results must be labeled separately from the fictional company scenarios.
