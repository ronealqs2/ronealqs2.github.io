Authentication Log Analysis

Analyzed authentication event types and retention limits in Event Viewer to explain what the available evidence supports.

Investigation Question and Method

What can retained authentication logs establish about account activity? I documented intentional incorrect-password attempts, reviewed failed-logon records and revisited Security and System logs in a later academic session.

Selected Evidence Interpretation

Interpretation examples from preserved academic logging exercises
EvidenceInterpretationAssessment consequence
Event 4624 with Logon Type 5.A service logon, rather than an interactive user logon.Do not count this event alone as evidence that a person signed in interactively.
A failed-logon filter returns no retained matches.No matching event is available in that filtered collection.Check retention, collection period, filters and audit coverage before concluding no failures occurred.

Practical Takeaway

State the collection period and event meaning before reporting a result. A missing retained record is an evidence gap, not proof that an activity never occurred.
