Python file inventory

Preserved source traverses a directory, filters files by size and writes file paths, sizes and timestamps to a text report. A saved output file supports the existence of a recorded run; the program has not been rerun during portfolio preparation.

Additional exercises

Saved examples include introductory HTML, JavaScript, VBScript and Node.js; an Express book-collection API; and SQL statements that create and update a sample employee table. These are academic examples, not production services.

GRC relevance

File-inventory scripting connects technical practice with repeatable information gathering. Documenting inputs, output fields, assumptions and limitations matters when scripts support evidence collection.

Limits and next validation

The Python source assumes Windows environment variables and writes to a fixed Desktop location. The Express example stores data in memory. Functional tests, input-boundary checks and security validation remain future work. No original paths, sample personnel records or code downloads are published.
